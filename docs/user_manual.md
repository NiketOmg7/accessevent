# Руководство пользователя AccessEvent

## 1. Регистрация и вход
1. Откройте главную страницу и нажмите «Регистрация».
2. Введите имя пользователя, email и пароль (минимум 8 символов).
3. Нажмите «Зарегистрироваться». Увидите подтверждение.
4. Для входа нажмите «Вход», введите email и пароль.

Для слабослышащих пользователей: все подтверждения показываются визуальными баннерами без звука.

## 2. Просмотр мероприятий
1. Откройте раздел «Мероприятия».
2. Используйте переключатель «Только инклюзивные», чтобы показать мероприятия с жестовым переводом и визуальными уведомлениями.
3. У инклюзивных мероприятий на карточке есть специальная метка.

## 3. Создание мероприятия (для организатора)
1. Войдите под аккаунтом организатора.
2. Заполните название, дату, место, описание; отметьте «Инклюзивное» при необходимости.
3. Сохраните — мероприятие появится в общем списке.
4. Успех подтверждается зелёным баннером.

## 4. Регистрация на мероприятие
1. Откройте карточку мероприятия и нажмите «Зарегистрироваться».
2. Ваша регистрация видна в личном кабинете.

## 5. Визуальные уведомления
Все уведомления ВИЗУАЛЬНЫЕ — без звуковых сигналов. Появляются в правом верхнем углу и исчезают через 4 секунды.

## 6. Тёмная тема
В шапке сайта есть кнопка ☀️/🌙 — переключение между светлой и тёмной темой. Выбор сохраняется между сессиями.

## 7. Личный кабинет
В профиле видны: имя, email, роль, список регистраций.
