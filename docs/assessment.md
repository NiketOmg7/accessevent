# Оценка ИС AccessEvent

## SWOT-анализ

| | Плюсы | Минусы |
|---|---|---|
| Внутреннее | **Силы:** инклюзивность на уровне архитектуры; автотесты в CI (14 тестов); контейнеризация | **Слабости:** нет push-уведомлений; тесты на SQLite, продакшен на PostgreSQL; нет пагинации |
| Внешнее | **Возможности:** рост аудитории; интеграция с календарями; субсидии | **Угрозы:** конкуренты с мобильными; обновления WCAG; утечка данных |

## Вывод о готовности
Система готова к опытной эксплуатации в ограниченном контуре. Основные функции реализованы и покрыты тестами, развёртывание автоматизировано. Перед публичным запуском — аудит безопасности, нагрузочное тестирование.

## Направления модернизации

### 1. Push-уведомления
Web Push API. Service Worker, VAPID. Визуальные push вместо звуковых.

### 2. Интеграция с календарём
Кнопка «Добавить в календарь» (iCal/Google Calendar). Генерация .ics.

### 3. Автоматические субтитры
Whisper или облачные API распознавания речи. Доступ к трансляциям.

### 4. Мобильное приложение (PWA)
Service Worker, офлайн-кеш. Уведомления и чат с телефона.
